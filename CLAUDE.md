# CLAUDE.md

## ⚠️ This is a public, open-source repository

Everything committed here is published publicly. **Never commit personal or sensitive information**, including:

- Personal data (real names, emails, phone numbers, usernames, home paths like `/Users/<name>/...`)
- Secrets and credentials (API keys, tokens, bot tokens, passwords, `.env` files)
- Private URLs, internal hostnames, IP addresses, or session/chat IDs
- Anything machine-specific or identifying

Before pushing, scan the diff for the above. Keep examples generic (`/path/to/project`, `YOUR_TOKEN_HERE`, `user@example.com`). If a value must exist, read it from an env var or local config that is git-ignored — never hardcode it.
